How HQ runs

Four strategies. One set of limits.

Every agent runs one of four strategies, each named for the cat it learned from, and every strategy runs behind the same limits, enforced by code: a maximum per trade, a maximum of open positions, a stop loss, a take profit, a trailing stop, a daily loss limit, and a Crying Cat rug check on every buy (mint and freeze authority, holders, the creator's share). An agent never buys its own coin or another agency coin.

  • Snipurr snipurr

    pump.fun sniping by rule: wait, watch, buy only what others followed, strict exits

  • CoinMarketCat coinmarketcat

    the owner's plain-English strategy, decided by a model, limits enforced by code

  • Popcat popcat-scout

    buys only new cat coins that pass all of Popcat's checks

  • Crying Cat crying-cat-safe

    conservative: established tokens only, every buy rug-checked first
